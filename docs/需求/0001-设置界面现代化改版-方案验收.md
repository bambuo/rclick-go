## 3. 发现并修复的问题

| 问题 | 处理 |
| --- | --- |
| 应用、命令等分区仍使用卡片背景，与平面分组方案不一致 | 改为带分隔线的平面分组行 |
| 操作分区显示内部 SF Symbol 名称 | 移除图标名字段 |
| 新建文件名称和扩展名输入框宽度固定，右侧留白过多 | 名称改为拉伸，扩展名保持固定宽度 |
| 文件夹文案「监听」与需求文档「监视」不一致 | 中文文案统一为「监视」 |
| 侧栏只有文字，分区识别度不足 | 新增六个 24×24 单色 SVG 图标，随选中态着色 |
| 无窗口测试中语言下拉为空 | 测试夹具补上「跟随系统」；真实窗口由 `refreshSettings` 设置 |

## 6. 复现步骤

```bash
go build ./...
go vet ./...
go test -count=1 ./...

mkdir -p /tmp/rclick-settings-check
go build -o /tmp/rclick-settings-check/rclick ./cmd/rclick
RCLICK_CONFIG=/tmp/rclick-settings-check/config.json RCLICK_OPEN_SETTINGS=1 /tmp/rclick-settings-check/rclick
```

真实窗口出现后用系统截图工具检查侧栏、六个分区和底部操作区；验收结束后关闭进程并删除临时目录。保存、还原与增删操作需在真实窗口中手工点击；本机自动化点击受“辅助访问”权限限制。
