## 1. 要解决的问题

改造前的设置窗口把标题、保存按钮、六段式切换控件和表单依次纵向排列，视觉层级弱，保存动作先于内容出现，六个分区的差异也不明显。用户确认需要中文优先、现代 macOS 风格的内容布局。

改造前状态：

- 设置页顶层结构为标题与保存按钮行、`ui.Segmented`、滚动内容、状态行；改造后由左侧 Sidebar 与右侧内容区替代。
- 六个分区的字段与处理函数保留，见 [settings.go](/Users/johana/Codes/github/rclick-go/internal/app/settings.go)。
- 改造前窗口默认 760×680、最小 620×480；改造后为 880×720、最小 700×560，见 [menu.go](/Users/johana/Codes/github/rclick-go/internal/app/menu.go#L59-L68)。
- 保存成功会刷新草稿、更新语言与托盘菜单并发送 `running`，见 [menu.go](/Users/johana/Codes/github/rclick-go/internal/app/menu.go#L117-L135)。

## 2. 约束事实

| 约束 | 事实 |
| --- | --- |
| 分区数量 | 现有六个：通用、应用、操作、新建文件、文件夹、命令 |
| 字段契约 | 不改配置 JSON 键，不改 Swift 解码字段 |
| 扩展契约 | 不改 FinderSync 通知、菜单结构和 helper 行为 |
| 保存行为 | 沿用现有校验、原子写入、`running` 通知和错误状态 |
| 视觉口径 | 中文优先；现代 macOS 设置风格；方向一「原生偏好」已确认 |
| 原型口径 | 完整模拟交互，但原型不写入真实配置 |
| 现有自动化测试 | 覆盖 config、i18n、services；没有设置界面 UI 测试 |

## 3. 候选方案对比

| 方案 | 布局策略 | 优点 | 代价 | 结论 |
| --- | --- | --- | --- | --- |
| 原生偏好 | 左侧六项分区导航，右侧单列分组，底部保存 | 最接近 macOS 系统设置；层级清楚；改动集中在设置界面 | 应用、命令等对象多的分区纵向较长 | 采用 |
| 双栏分组 | 左侧导航，右侧两栏表单 | 一屏信息密度高 | 620 宽度下拥挤；双栏对齐与窄窗折叠成本高 | 排除 |
| 主从编辑 | 左侧导航，对象列表与详情并列 | 单个应用或命令编辑集中 | 通用页结构过重；对象列表与详情需要更大范围重构 | 排除 |

## 4. 采用方案与理由

采用「原生偏好」：左侧固定六项分区导航，右侧使用页面标题、说明、单列分组表单，保存与还原放在内容底部。理由是它保留现有六段结构与字段，视觉上贴近 macOS 设置，改动范围只落在设置界面。

用户在 2026-11-07 确认方向一「原生偏好」，并确认覆盖全部六个分区、现代 macOS 风格和完整模拟交互。

## 5. 实测证据

- 对话内 HTML 原型包含六个分区，结构与脚本语法检查通过；用户已查看并确认方向一。
- 无窗口 UI 测试通过：六个侧栏项可见，点击「应用」后内容切换，保存按钮初始禁用、脏状态启用；700×560 渲染无裁切，侧栏项仍可访问。
- 真实窗口验证通过：macOS 26.7.2 arm64 深色模式下以临时配置启动 880×720 设置窗口，侧栏、内容区和底部操作区无裁切；测试实例已关闭，临时配置已删除。
- 完整功能回归尚未执行：添加与移除对象、保存与还原、保存失败、语言切换和 Finder 菜单回归仍待补测。

## 6. 风险与观察项

- 应用与命令分区内容较长，保存按钮位于内容底部；用户需要滚动后才能检查完整字段。
- 新增中文说明文案会增加行高与换行，需继续检查中英文切换和窄窗口表现。
- 没有设置界面自动化回归覆盖添加、移除和保存链路，相关交互仍需 macOS 实机补测。
- 真实窗口验证只覆盖布局与深色模式，未验证 Finder 菜单加载和保存后的扩展刷新。

## 7. 复现方式

1. 查看现有设置界面：在 macOS 环境执行 `RCLICK_OPEN_SETTINGS=1 make dev`，打开设置窗口。
2. 对照代码：查看 [settings.go](/Users/johana/Codes/github/rclick-go/internal/app/settings.go#L33-L78) 的顶层布局与 [menu.go](/Users/johana/Codes/github/rclick-go/internal/app/menu.go#L59-L68) 的窗口尺寸。
3. 对照原型：查看 2026-11-07 对话内的「原生偏好」HTML 原型，切换六个分区并操作开关、输入和保存按钮。

`make dev` 需要本机 macOS 与 Xcode 命令行工具；本次方案评估未执行该命令。
