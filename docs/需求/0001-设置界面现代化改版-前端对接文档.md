# 0001 设置界面现代化改版 — 前端对接文档

> 分支：main（本地） ｜ 日期：2026-11-07 ｜ 状态：实现完成，布局验证通过

## 1. 接口与权限

本需求不新增网络接口、RPC 或消息通道。设置窗口在本地读取和保存共享配置，沿用现有文件权限与 Finder 扩展权限；不新增账号、角色或授权范围。

## 2. 字段说明

以下为界面展示分组，字段含义与现有设置保持一致，不改变配置键。

| 分区 | 展示内容 | 控件 |
| --- | --- | --- |
| 通用 | Finder 菜单开关、新建文件默认值、复制分隔符、Open With 全局参数与环境、语言、登录启动、Dock | 开关、文本框、下拉框 |
| 应用 | 打开方式应用、显示名称、应用路径、继承参数、继承环境、参数、环境变量 | 文本框、开关、原生文件选择器 |
| 操作 | 复制路径、直接删除、隐藏、取消隐藏、隔空投送 | 开关、重置按钮 |
| 新建文件 | 文件类型名称、扩展名、启用状态 | 文本框、开关、添加与移除 |
| 文件夹 | 常用文件夹名称与路径、监视文件夹路径 | 文本框、原生文件夹选择器、添加与移除 |
| 命令 | 命令名称、启用状态、危险确认、命令模板 | 文本框、多行文本、开关、添加与移除 |

## 3. 接口示例

无接口请求。保存流程为本地操作：

| 步骤 | 用户可见行为 |
| --- | --- |
| 1 | 用户编辑设置，底部状态显示未保存，保存与还原可用 |
| 2 | 用户点击保存，主程序校验并写入共享配置 |
| 3 | 保存成功后状态显示已保存，Finder 扩展收到刷新通知 |
| 4 | 保存失败时状态显示错误信息，草稿保留 |

## 4. 错误文案

| 场景 | 文案 |
| --- | --- |
| 有未保存修改 | 未保存更改 |
| 保存成功 | 已保存 |
| 保存失败 | 保存失败：<错误信息> |
| 还原完成 | 已恢复到已保存的配置 |
| 新建类型名称为空 | 请输入模板名称 |
| 登录项更新失败 | 登录项：<错误信息> |

新增文案以实施后的中英文 i18n 资源为准；错误信息来自本地配置存储或系统登录项调用。

## 5. 注意事项

- 不修改配置 JSON 键、Finder 扩展通知或原生 helper 命令。
- 应用与文件夹继续使用系统原生选择器，不实现自绘弹窗。
- 设置保存在底部；有未保存修改时保存与还原可用。
- 切换分区不会丢弃草稿；关闭窗口时沿用现有行为。
- 语言支持跟随系统、简体中文和英文；明暗主题跟随系统。
- 联调使用临时配置，不执行真实删除、AirDrop 或快捷命令操作。
