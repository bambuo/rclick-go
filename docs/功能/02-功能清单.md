## 功能入口

| 模块 | 能力/入口 | 鉴权 | 状态 | 备注 |
| --- | --- | --- | --- | --- |
| 应用 | 菜单栏、设置窗口、单实例启动、启动时打开设置 | 本地用户会话 | 已实现 | `RCLICK_OPEN_SETTINGS=1` 可在启动时打开设置 |
| Finder 菜单 | `open`、`actioning`、`Create File`、`common-dirs`、`quick-command` | 本地 Finder 通知 | 已注册 | 由 FinderSync 扩展发送，Go 路由分发 |
| 生命周期通知 | `heartbeat`、`running`、`quit` | 本机进程间通知 | 已注册 | `running`/`quit` 的回声不再次处理 |
| 文件动作 | `copy-path`、`delete-direct`、`hide`、`unhide`、`airdrop` | Finder 菜单配置 | 默认启用 | 受保护路径、目录和容器触发有分支限制 |
| Open With | 按应用 ID 启动应用，可合并全局/单应用参数和环境变量 | Finder 菜单配置 | 已实现 | helper 缺失则失败 |
| 新建文件 | JSON、TXT、Markdown、DOCX、PPTX、XLSX；可选模板 | Finder 菜单配置 | 默认启用 | 名称冲突时递增编号 |
| 常用目录 | 按配置路径打开一个或多个目录 | Finder 菜单配置 | 已实现 | 默认目录项由配置提供 |
| 快捷命令 | 展开选中文件占位符后执行配置的 shell 命令 | Finder 菜单配置；危险命令二次确认 | 已实现 | 运行环境为 `/bin/zsh -lc` |
| 配置 | 读、校验、保存与通知 FinderSync 刷新 | 本地文件权限 | 已实现 | 原子写入；键名是 Go/Swift 契约 |
| 启动登录 | 设置 macOS 登录启动项 | 本机用户权限 | 已实现 | 通过 mygo 应用 API 设置 |

证据：[`internal/app/router.go`](../../internal/app/router.go#L11-L96)、[`internal/config/defaults.go`](../../internal/config/defaults.go#L49-L78)、[`internal/app/settings.go`](../../internal/app/settings.go#L123-L143)。
