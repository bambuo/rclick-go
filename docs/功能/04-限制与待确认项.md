## 已确认边界

- 产品依赖 macOS FinderSync、AppKit/Cocoa 和本机 helper；不是通用跨平台桌面程序。Go 侧外部调用包括 Finder 通知与 helper IPC。
- 项目没有 HTTP/gRPC API、数据库、消息队列或 worker/cron 任务入口。
- 快捷命令按配置模板在本机 `/bin/zsh -lc` 执行；命令具有本机用户权限。被标记为危险的命令会确认，但这不等价于沙盒或通用安全隔离。
- `copy-path` 仅复制首个目标；容器触发的直接删除被拒绝；容器触发的 AirDrop 不执行。
- helper 不可用时，依赖原生能力的操作无法完成；主程序仍可创建托盘和设置界面。
- app 的 Finder 扩展安装、PlugInKit 注册和代码签名需要 macOS/Xcode 环境；本次文档任务未执行这些系统操作。

## 安全与运行注意

- 不把真实配置文件、应用路径或命令内容复制进公共文档；环境变量只记录名称与用途。
- 修改快捷命令配置前，应审阅其实际 shell 内容和目标路径；危险标记由配置决定，不应替代用户对命令的审查。
- 配置 JSON 是 Go 与 Swift 间的共享契约，破坏键名会影响 Finder 扩展读取。
- 遇到扩展加载、目录授权或系统弹窗问题时，需在对应 macOS 版本上实测；源码静态检查不能替代系统行为验证。
