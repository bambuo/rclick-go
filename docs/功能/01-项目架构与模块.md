## 启动顺序

1. `main` 配置日志并调用 `config.Open`；配置错误会记录，应用仍使用返回的 store 继续启动。
2. `App.Run` 设置 UI 属性并取得单实例锁，待 UI ready 后进入初始化。
3. ready 回调启动 helper；helper 不可用时仍建立应用与设置界面，但依赖 helper 的操作无法完成。
4. 创建服务、托盘和设置窗口，然后发送 `running` 通知；退出时通知并关闭 helper。

## 配置契约

配置默认位置为 `~/Library/Application Support/RClick/config.json`，也可由 `RCLICK_CONFIG` 覆盖。Go 写入 JSON，FinderSync 读取同一文件。顶层键：`schemaVersion`、`revision`、`updatedAt`、`apps`、`actions`、`newFiles`、`commonDirs`、`permissionDirs`、`quickCommands`、`menu`、`defaults`、`ui`。键名变更需同步 Go 和 Swift，不应仅修改一侧。

配置保存会规范化并校验，递增 revision、更新时间，再原子替换文件；失败时不更新当前配置。设置保存后的 `running` 通知促使扩展刷新。损坏配置文件不会被覆盖，store 回退到默认值并返回错误。

## 构建与验证入口

`make build`、`make test`、`make vet` 使用 Go 工具链；`make helper`、`make finder` 和 `make package` 还需要 macOS/Xcode 工具。具体命令以根 [Makefile](../../Makefile#L5-L52) 为准。
