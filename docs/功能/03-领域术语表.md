# 03 领域术语表

> 文档编号：03
> 项目：RClick
> 状态：术语基线 v1
> 证据基线：当前工作区源码；无 Git commit 信息。
> 范围：Go 主程序、FinderSync 扩展、Swift helper 与配置 JSON。

## 使用规则

同一概念优先使用“Finder 扩展”“原生 helper”“配置动作”等主术语。代码字段和消息值保留原拼写；本表不要求重命名代码或 JSON 契约。

## 核心术语

| 主术语 | 英文/代码映射 | 定义 | 允许别名 | 避免用法 |
| --- | --- | --- | --- | --- |
| 主程序 | Go app / `cmd/rclick` | 托盘、设置界面、配置与业务路由所在进程 | Go 应用 | 将它称为服务端/API 服务 |
| Finder 扩展 | FinderSync / `RClickFinderSync` | 构造 Finder 菜单、读取配置并发出通知的 appex | 扩展 | 与 helper 混称“插件进程” |
| 原生 helper | `RClickHelper` / `ipc.Helper` | 通过 stdin/stdout 与 Go 通信并调用 macOS 原生能力的进程 | helper | 与 Finder 扩展混用 |
| Finder 消息 | IPC payload / `Payload` | helper 转发给 Go 的 JSON 事件 | IPC 事件 | HTTP 请求、RPC 请求 |
| 动作 | `actions` / `rid` | Finder 发送的配置动作 ID；文件类动作由 `actioning` 承载 | Finder 动作 | 与快捷命令混为一类配置 |
| 目标 | `target` | 消息携带的路径数组，按动作语义解释 | 路径 | 将其理解为 URL 或网络目标 |
| 触发来源 | `trigger` | Finder 菜单触发上下文，如 `ctx-container` | 菜单上下文 | 认证触发器 |
| Open With | `apps` / `OpenWithApp` | 指定用某应用打开目标，并可继承全局参数和环境变量 | 打开方式 | 泛指所有应用启动 |
| 新建文件类型 | `newFiles` / `NewFile` | 配置的扩展名、显示名称和可选模板 | 文件模板类型 | 不带限定的“模板” |
| 快捷命令 | `quickCommands` / `QuickCommand` | 针对 Finder 目标展开模板并在本机 shell 执行的命令 | shell 命令 | 服务端任务、后台任务 |
| 常用目录 | `commonDirs` / `CommonDir` | Finder 菜单中可直接打开的配置路径 | 快捷目录 | `permissionDirs` |
| 权限目录 | `permissionDirs` / `PermissionDir` | `running` 通知携带的目录路径集合；Finder 扩展依赖它维持目录访问 | 授权目录（仅说明语境） | 用户收藏目录 |
| revision | `revision` | 配置保存时递增的版本号，用于变更识别 | 配置修订号 | 业务对象版本状态 |

## 易混概念

| 对照 | 区别 | 推荐口径 |
| --- | --- | --- |
| Finder 扩展 / helper | 扩展提供 Finder 菜单并发通知；helper 转发通知并调用原生 API | 依职责称呼，不统称 helper 插件 |
| `actions` / `quickCommands` | 前者映射固定 Go 处理分支；后者执行用户配置的命令模板 | 文档中分别称“文件动作”和“快捷命令” |
| `commonDirs` / `permissionDirs` | 前者是用户可打开的菜单目标；后者随运行状态通知传递给扩展 | 不把两者都称为“常用目录” |
| `running` / `heartbeat` | `running` 通知状态；heartbeat 是扩展请求刷新状态的动作 | 描述消息方向时使用完整名称 |
| `.url` / target path | `OpenWithApp.URL` 保存应用 bundle 路径；消息 `target` 是选择项路径 | 按字段上下文说明，避免误解为网络 URL |

## 代码与数据映射

| 领域概念 | Go 字段/类型 | Swift 对应 | 说明 |
| --- | --- | --- | --- |
| 配置版本 | `Config.SchemaVersion`, `Config.Revision` | SharedConfigStore 解码字段 | JSON 名称分别为 `schemaVersion`、`revision` |
| 菜单动作 | `Action.ID` | `RCAction` / payload `rid` | Go 根据 ID 路由 |
| 打开应用 | `OpenWithApp` | `OpenWithApp` | JSON 中的 URL 是应用路径 |
| 快捷命令 | `QuickCommand` | `QuickCommand` | 模板由 Go 服务展开后交 shell 执行 |
| 目录 | `CommonDir`, `PermissionDir` | `CommonDir` 及配置读取逻辑 | 两者用途不同 |

## 维护规则

新增配置字段或消息动作时同步更新本表与功能清单；跨语言 JSON 键需同步 Go/Swift。当前只统一文档口径，没有修改代码或数据字段。
